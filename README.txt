OpenList Google Drive integration website

Files: index.html (homepage), privacy.html (privacy policy).

Publish these files in the root of a public GitHub repository and enable GitHub Pages
from the main branch and root folder. Enter the resulting homepage URL and its
/privacy.html URL in Google Cloud Branding.

Review these pages to ensure they accurately reflect your actual OpenList hosting
and data handling. Publishing a website does not guarantee Google OAuth verification
or production approval.
