Privacy Policy

Last updated: November 14, 2026

This policy describes the personal OpenList integration used by its account owner to connect an OpenList instance to Google Drive.

Information accessed

With the user's consent, OpenList may access Google Drive information permitted by the OAuth scopes displayed during authorization. Depending on the configured OpenList driver, this can include file and folder names, identifiers, metadata, and file contents when the user requests them.

How information is used

Google Drive information is used to display and manage the user's own Drive files through the user's OpenList instance. OAuth credentials and tokens are configured in that OpenList instance and are used to maintain the authorized connection.

Sharing and sale

This personal integration does not sell Google user data or use it for targeted advertising. It does not intentionally disclose Google user data to unrelated third parties. Data may be transmitted between Google and the user's OpenList hosting environment as needed to provide the requested file access.

Storage and security

The account owner is responsible for the security, hosting, access controls, backups, and retention settings of their OpenList instance. Anyone with administrative access to that instance may be able to access its configured tokens and connected files. Users should protect their OpenList credentials and hosting environment.

Data retention and deletion

Google Drive files remain in the user's Google account unless the user takes an action that changes them. OpenList may retain configuration data, cache, or logs according to the instance owner's settings. The account owner can remove the Google Drive storage configuration from OpenList. Removing the configuration does not itself delete files stored in Google Drive.

Revoking access

The user can revoke the integration's access through their Google Account security settings. Revoking access prevents the integration from obtaining new access tokens for that authorization.
