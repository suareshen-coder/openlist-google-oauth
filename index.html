OpenList Drive Integration

This website provides information about a personal integration that connects an OpenList instance to Google Drive.

The integration is used by the account owner to access files and folders in their own Google Drive through their OpenList instance.

Operator: Personal use by the account owner.
Contact: suareshen@gmail.com

Google user data

When the user authorizes the integration, OpenList uses the permissions shown on Google's consent screen to access the user's Google Drive. The integration does not offer Google user data for sale or use it for advertising.

Access can be revoked at any time from the user's Google Account security settings.
